# GSAP Lab
Experimental repository for **GSAP (GreenSock Animation Platform)**. This lab is designed to document the library's learning process and centralize the development of reusable animation resources.

## 📂 Organization
- **`/playground`**: Atomic tests and practical exercises.
- **`/utils`**: Abstract animation functions ready to be integrated into real-world projects.
- **`/project`**: Implementation of a cohesive interface applying the developed techniques.
